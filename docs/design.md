# Re-Wired FM visual system

The approved direction pairs near-black and deep plum with warm ivory, champagne gold, editorial typography, original celestial artwork, and a full-width moving aurora. It applies to onboarding, Today, Library, My Path, lesson detail, the full player and persistent mini-player. The app uses React Native components, not mockup screenshots or a WebView.

Approved references: [full direction](approved-direction.png) and [player refinement](approved-player.png). These documentation images are never rendered by the app.

Production screenshots: [Today](screenshots/today.png), [Library](screenshots/library.png), [Player](screenshots/player.png). These are captures of the working app at 390px.

## Palette and typography

`src/ui/theme.ts` is the source of truth. Background `#08060B`, surface `#120D18`, warm text `#FAF5E9`, secondary text `#B7ACBF`, and primary gold `#EEC676`. Purple and teal belong mainly to the art; the player aurora now uses muted bronze, champagne and gold. Headings and practice titles use bundled Cormorant Garamond Medium; controls and paragraphs use DM Sans. Font licenses and provenance live in `assets/fonts`. Fonts load at runtime with Expo Font, allowing the same UI in Expo Go and web. A font loading error does not prevent the app from opening.

Use spacing and hairline separators instead of outlining every section. Primary actions use restrained satin gold, rounded rectangular buttons. Cover images use modest corner radii and consistent cropping. Practice rows and progress marks stay visually quiet. Demo labels and the distinction between ambient samples and reflective reading remain visible.

## Player and aurora

`src/ui/PlayerControls.tsx` owns the gold medallion, solid transport glyphs, matching 15-second controls and speed/text/save toolbar. Screen components connect them to the audio provider; they do not create players or alter session configuration. `src/ui/SeekBar.tsx` uses the existing Expo-compatible native UISlider/Android SeekBar with gold tint and iOS track tapping; web retains the custom gold track and a real range input for keyboard/pointer access. The screen keeps normal vertical scrolling: the native slider handles horizontal drags, and the browser range allows vertical pans. Cancellation clears only local drag state, avoiding a screen-wide scroll lock. Incoming transport ticks cannot move the finger-held thumb, and the released target stays visible until acknowledged. Native seeks use exact tolerances and serialize rapid requests, retaining the newest target. VoiceOver/TalkBack can adjust by 15 seconds. Interactive targets are at least 44 points. Native finger gestures and assistive technology still need device validation.

`src/ui/PlaybackVisualizer.tsx` renders four filled champagne/gold Bézier ribbons with soft gradient edges. Their geometry lives in `auroraGeometry.ts`. The effect spans the screen with explicit stacking underneath the player foreground and never captures taps. Phone layouts use outer opacity about 0.53 idle and 0.82 playing; wide layouts use 0.37 and 0.64 so a much larger ribbon does not look solid. Both use the same paths and direct gradients, before each ribbon's soft transparency. This makes the wave visible against black while fading edges and muted gold preserve text and control readability. It is an atmospheric visualization, not measured audio frequencies.

SVG blur filters and masks have been removed: the iOS renderer creates large offscreen bitmaps and Core Image results for those operations on every redraw. Gradient softness draws directly; four ribbons use 28 cubic segments each instead of six using 56, reducing geometry work by two thirds.

The actual path shapes morph on the native UI thread using the project's already-installed Reanimated/worklets modules; this is no longer a translated static texture. Harmonics travel rightward at different speeds while their amplitude and thickness breathe. A 30-fps frame callback limits geometry work, and each ribbon has a modest fixed number of cubic segments. Adjacent segments reuse their endpoints, reducing trigonometric point evaluations from 58 to 30 per ribbon without changing its shape. Animation stops when the player route loses focus as well as when the app backgrounds. The main phase repeats in 10 seconds during playback and 26 seconds while idle; speed changes preserve phase and smoothly change tempo. All harmonics complete a continuous cycle, avoiding a visible reset. Playback increases amplitude and opacity over 1.4 seconds. Reduce Motion freezes shape changes and removes the intensity transition. Backgrounding stops only visual animation. No microphone, frequency sampling, JS-frame timer or new native dependency is used. Warm native resumes skip repeated asynchronous setup, and pause feedback does not wait for position polling. Physical iPhone performance is still a required check.

## Responsive behavior

Phone navigation stays at the bottom, above the device safe area; desktop uses a quiet sidebar. The player uses available height to size its cover art and switches to a two-column layout on wide screens. Content scrolls for shorter screens and larger text. Search filters scroll horizontally; featured text containers can grow. Text scaling is enabled except for the fixed numeral drawn inside the skip icon.

## Assets and future changes

The three original AI-generated illustrations remain in `assets/artwork` as editing masters. The app bundles optimized JPEG covers and 288px thumbnails from `assets/artwork/optimized`, with a replaceable map in `src/ui/CosmicArt.tsx`. Artwork dropped from 6,567,857 to 598,678 bundled bytes (90.9% smaller); small rows no longer decode full covers. The favicon has its own 128px source. `scripts/optimize-artwork.py` regenerates these assets; Pillow is an editing tool, not an app dependency. The artwork README describes provenance and replacement. Illustrative audio, lesson IDs, recommendations, listening paths, persistence, account/purchase boundaries, runtime version and stable Expo channel retain their existing behavior. Final recordings and commissioned artwork can replace the bundled samples independently of the screens.

For each visual iteration, run TypeScript and browser flows, inspect a 320/390-pixel layout and a desktop layout, verify larger text and Reduce Motion, then build the Pages export. Publishing to the existing Expo channel keeps the user-facing launch link stable. The device checklist in the main README covers native animation, gestures, screen-lock playback and interruptions.
